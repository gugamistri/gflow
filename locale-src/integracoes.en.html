Integrations

Use GuiaFlow from your AI assistant: connect the MCP server and ask it to build, edit and publish guided tours from screenshots. Pro plan only; sign-in happens in the browser (OAuth), no key to copy.

Server URL

https://app.guiaflow.pro/mcp

Streamable HTTP, OAuth 2.1. API keys also work (Authorization: Bearer gf_live_…), see API and MCP.

Also on Smithery

Cursor

Add to Cursor
  1. Click Add to Cursor and confirm with Install.
  2. On first use, Cursor opens the GuiaFlow sign-in: sign in and pick the permissions.

Or paste into ~/.cursor/mcp.json:

{
  "mcpServers": {
    "guiaflow": { "url": "https://app.guiaflow.pro/mcp" }
  }
}

Claude Code

Run in your terminal:

claude mcp add --transport http guiaflow https://app.guiaflow.pro/mcp

Inside Claude Code, run /mcp, pick guiaflow and sign in.

Claude.ai

  1. Open Settings → Connectors and click Add custom connector.
  2. Name: GuiaFlow. URL: https://app.guiaflow.pro/mcp.
  3. Click Connect and sign in to GuiaFlow. In a chat, enable the connector from the tools menu.

Also works in Claude Desktop. On Team/Enterprise plans, an admin adds the connector for the organization.

ChatGPT

  1. In Settings → Apps & Connectors → Advanced settings, turn on Developer mode.
  2. Back in Apps & Connectors, click Create.
  3. Name: GuiaFlow. MCP server URL: https://app.guiaflow.pro/mcp. Authentication: OAuth. Confirm and sign in.
  4. In a chat, pick Developer mode from the + menu and enable GuiaFlow.

Developer mode is available on paid ChatGPT plans on the web.

VS Code

Install in VS Code
  1. Click Install in VS Code and confirm with Install.
  2. On first use, VS Code asks you to sign in to GuiaFlow.

Or paste into .vscode/mcp.json:

{
  "servers": {
    "guiaflow": { "type": "http", "url": "https://app.guiaflow.pro/mcp" }
  }
}

What to ask

Examples: “Build a tour from these 4 screenshots and publish it”, “Write the step copy with AI”, “How many people finished the checkout tour this week?”.
