Integraciones

Usa GuiaFlow desde tu asistente de IA: conecta el servidor MCP y pídele crear, ajustar y publicar tours guiados a partir de capturas de pantalla. Exclusivo del plan Pro; el login es en el navegador (OAuth), sin clave que copiar.

Dirección del servidor

https://app.guiaflow.pro/mcp

Streamable HTTP, OAuth 2.1. También acepta clave de API (Authorization: Bearer gf_live_…), mira API y MCP.

También en Smithery

Cursor

Añadir a Cursor
  1. Haz clic en Añadir a Cursor y confirma en Install.
  2. En la primera llamada, Cursor abre el login de GuiaFlow: entra y elige los permisos.

O pega en ~/.cursor/mcp.json:

{
  "mcpServers": {
    "guiaflow": { "url": "https://app.guiaflow.pro/mcp" }
  }
}

Claude Code

Ejecuta en la terminal:

claude mcp add --transport http guiaflow https://app.guiaflow.pro/mcp

Dentro de Claude Code, ejecuta /mcp, elige guiaflow e inicia sesión.

Claude.ai

  1. Abre Configuración → Conectores y pulsa Añadir conector personalizado.
  2. Nombre: GuiaFlow. URL: https://app.guiaflow.pro/mcp.
  3. Pulsa Conectar e inicia sesión en GuiaFlow. En una conversación, activa el conector en el menú de herramientas.

Funciona también en Claude Desktop. En planes Team/Enterprise, un administrador añade el conector para la organización.

ChatGPT

  1. En Configuración → Apps y conectores → Configuración avanzada, activa el Modo desarrollador.
  2. Vuelve a Apps y conectores y pulsa Crear.
  3. Nombre: GuiaFlow. URL del servidor MCP: https://app.guiaflow.pro/mcp. Autenticación: OAuth. Confirma e inicia sesión.
  4. En una conversación, elige Modo desarrollador en el menú + y activa GuiaFlow.

El modo desarrollador está disponible en los planes de pago de ChatGPT en la web.

VS Code

Instalar en VS Code
  1. Haz clic en Instalar en VS Code y confirma en Install.
  2. En la primera llamada, VS Code pide el login de GuiaFlow.

O pega en .vscode/mcp.json:

{
  "servers": {
    "guiaflow": { "type": "http", "url": "https://app.guiaflow.pro/mcp" }
  }
}

Webhook de leads

En el editor, abre los contactos del enlace permanente. La sección Webhook (Pro) envía cada contacto a una dirección https, firmado.

  1. Pega la URL https del destino (Make, n8n, Zapier, LeadPronto o tu propio sistema).
  2. Genera un secreto whsec_… o pega el que creó el destino. Después puedes revelarlo y girarlo.
  3. Guarda y usa Enviar prueba. El último envío aparece en la misma sección.

El contacto lleva el origen de la visita: los parámetros utm_* y el sitio del que llegó la persona.

Recetas para crear una tarjeta en Pipefy, una fila en Google Sheets o un lead en Pipedrive, con modelos de Make y de n8n: Leads en Make, n8n y Zapier. En Zapier el disparador es Webhooks by Zapier.

RD Station Marketing

En el editor, abre los contactos del enlace permanente. La sección RD Station Marketing (Pro) convierte cada contacto en una conversión.

  1. En RD Station Marketing, crea una aplicación en la App Store y genera la clave de API pública.
  2. Pega la clave, guarda y usa Enviar prueba. La clave no vuelve a aparecer: solo los 4 últimos caracteres.
  3. Desconectar deja de enviar. Para cambiar la clave, pega otra y guarda.

El evento de conversión es el título del tour, o el slug si el título está vacío. Nombre, correo, teléfono, UTMs y el consentimiento van en los campos de RD Station. Mensaje, idioma y el origen de la visita van en campos cf_guiaflow_*.

HubSpot

En el editor, abre los contactos del enlace permanente. La sección HubSpot (Pro) crea o actualiza el contacto por el correo. Puedes usar un token de app privada o, cuando esté disponible, OAuth. Conectar por un método sustituye al otro.

Token de app privada

  1. En HubSpot, abre Configuración > Integraciones > Aplicaciones privadas y crea una app.
  2. Marca los permisos crm.objects.contacts.read, crm.objects.contacts.write, crm.schemas.contacts.read y crm.schemas.contacts.write.
  3. Copia el token pat-…, pégalo en el campo de contraseña y guarda. El token no se queda en el navegador: la sección muestra el método y solo los 4 últimos caracteres.

OAuth

  1. Cuando OAuth esté disponible, haz clic en Conectar con HubSpot y autoriza GuiaFlow.
  2. La otra opción en el mismo lugar es usar token de app privado.

En el mapeo, el valor es el nombre interno de la propiedad. Déjalo en blanco para no enviar ese campo. Guarda, activa o desactiva el envío y usa Enviar prueba. La sección muestra el método (OAuth o token ····1234), la cuenta, los permisos, los fallos y las últimas entregas. Desconectar quita la cuenta de este enlace. Si OAuth no está disponible, el botón Conectar queda oculto y el token es el camino.

LeadPronto

En el editor, abre los contactos del enlace permanente. La sección LeadPronto (Pro) envía los contactos de la cuenta a LeadPronto, sin pegar dirección ni secreto.

  1. Haz clic en Conectar con LeadPronto y autoriza en LeadPronto.
  2. Al volver, la sección muestra Conectado a tu empresa. Elige todos los tours o solo algunos, y enciende o apaga el envío.
  3. Desconectar deja de enviar.

Qué pedir

Ejemplos: “Crea un tour con estas 4 capturas y publícalo”, “Escribe los textos de los pasos con IA”, “¿Cuántas personas completaron el tour del checkout esta semana?”.
