Open-source interactive demos, free in your browser

GuiaFlow is an open-source (MIT) editor and player for click-through demos and photo galleries. Open the editor in your browser with no account and no card, or run it locally from GitHub. It is an alternative to Arcade, Supademo and Storylane. You can export a single HTML file and host it yourself. GuiaFlow Pro (US$ 7/month) adds permanent links, embeds, analytics, lead capture, hosted AI and an MCP server.

Run it locally, or use it in the browser

To run the editor and player on your computer, clone gugamistri/gflow and start it from the README:

npm start

That opens the landing at http://localhost:4173 and the editor at http://localhost:4173/editor. You can also use the hosted editor at guiaflow.pro/editor, free, with no account. After you export a single HTML file, you can publish that file on any static hosting you already use.

FAQ

Is GuiaFlow really open source?

Yes. The editor and player are MIT-licensed, and the source code is at github.com/gugamistri/gflow.

Do I need an account?

Not for the free editor. You can open it in the browser with no account and no card.

Can I run GuiaFlow on my computer, or host the demo myself?

The editor and player run in the browser, including locally from the GitHub repository (npm start). You can export a single HTML file and host it on any static hosting. GuiaFlow Pro hosting is separate code; there is no Docker package for running the full Pro product on your own server.

Is the free player branded?

Yes, and so is the free MP4. Pro removes the GuiaFlow mark from the player and the video.

Does it support branching?

No, tours are linear. Gallery mode lets viewers browse freely, which is not branching.

Is GuiaFlow the same as Guideflow?

No. GuiaFlow (guiaflow.pro) and Guideflow (guideflow.com) are different products.
