Integrações

Use o GuiaFlow direto do seu assistente de IA: conecte o servidor MCP e peça para criar, ajustar e publicar tours guiados a partir de capturas de tela. Exclusivo do plano Pro; o login é pelo navegador (OAuth), sem chave para copiar.

Endereço do servidor

https://app.guiaflow.pro/mcp

Streamable HTTP, OAuth 2.1. Também aceita chave de API (Authorization: Bearer gf_live_…), veja API e MCP.

Também no Smithery

Cursor

Adicionar ao Cursor
  1. Clique em Adicionar ao Cursor e confirme em Install.
  2. Na primeira chamada, o Cursor abre o login do GuiaFlow: entre e escolha as permissões.

Ou cole em ~/.cursor/mcp.json:

{
  "mcpServers": {
    "guiaflow": { "url": "https://app.guiaflow.pro/mcp" }
  }
}

Claude Code

Rode no terminal:

claude mcp add --transport http guiaflow https://app.guiaflow.pro/mcp

Dentro do Claude Code, rode /mcp, escolha guiaflow e faça login.

Claude.ai

  1. Abra Configurações → Conectores e clique em Adicionar conector personalizado.
  2. Nome: GuiaFlow. URL: https://app.guiaflow.pro/mcp.
  3. Clique em Conectar e faça login no GuiaFlow. Em uma conversa, ative o conector no menu de ferramentas.

Funciona também no Claude Desktop. Em planos Team/Enterprise, um administrador adiciona o conector para a organização.

ChatGPT

  1. Em Configurações → Apps e conectores → Configurações avançadas, ative o Modo desenvolvedor.
  2. Volte em Apps e conectores e clique em Criar.
  3. Nome: GuiaFlow. URL do servidor MCP: https://app.guiaflow.pro/mcp. Autenticação: OAuth. Confirme e faça login.
  4. Em uma conversa, escolha Modo desenvolvedor no menu + e ative o GuiaFlow.

O modo desenvolvedor está disponível nos planos pagos do ChatGPT na web.

VS Code

Instalar no VS Code
  1. Clique em Instalar no VS Code e confirme em Install.
  2. Na primeira chamada, o VS Code pede o login do GuiaFlow.

Ou cole em .vscode/mcp.json:

{
  "servers": {
    "guiaflow": { "type": "http", "url": "https://app.guiaflow.pro/mcp" }
  }
}

O que pedir

Exemplos: “Crie um tour com estas 4 capturas e publique”, “Escreva os textos dos passos com IA”, “Quantas pessoas concluíram o tour do checkout esta semana?”.

Ferramentas, permissões, limites e API REST: API e MCP. Dúvidas: contato@guiaflow.pro.
